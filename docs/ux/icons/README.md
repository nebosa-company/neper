# Icons

Neper Icons, 55 glyphs: a 24px grid, 1.75px strokes, round caps and joins, a 2px live-area inset. The SVG files are drawn in one ink (#1b1c20, near `on-surface` in light), so as `<img>` they read only on light grounds.

In components, inline the path data with `stroke="currentColor"`, so the icon takes the colour of the label it sits with. Show them at 18 (`icon-sm`) in buttons and chips, 24 (`icon-md`) in bars, lists and icon buttons, and 36 (`icon-lg`) in empty states. `star-filled` is the selected form of `star`.
