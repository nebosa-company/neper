About Neper

Neper is an MIT-licensed, self-hosted systems programming language optimized end to end for LLM-generated software. One toolchain builds deterministic native code for Windows, Linux and macOS, on CPU and GPU, with no virtual machine.

What the project is

The compiler and linker are written in Neper and build themselves; a byte-identical compiler fixed point is part of the build. The standard library is written in Neper too, and benchmarks in the blog can be reproduced from the scripts in the repository.

Compiler throughput, binary size and target support are stated with the measurements on the home page and in the blog. Where a number has a reproduction script, the post names it.

Who maintains it

Neper is maintained by the Neper project in the nebosa-company organization on GitHub. The repository holds the source, the suites that verify it, and the design-decisions log that records why the language is shaped the way it is; changes arrive through pull requests there.

License

Neper is released under the MIT license. You can use, modify and redistribute it, including commercially, under that license's terms.

Contact

Bug reports, feature requests and questions go to GitHub issues; the community chat is the project Discord. The contact page lists the same channels.
