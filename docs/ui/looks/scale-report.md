Written by `python scripts/looks_scale_check.py --report`. For every Windows sheet (light look, text left out) the table gives the share of runs of 8 or more equal pixels of the 1.0 render (16 for the popup menus, the toolbar and the page control) that are a clean scaling in the 1.25, 1.5 and 2.0 renders. Each cell is `exact/near`: the share of runs that are exactly the 1.0 run scaled, and the share that are flat and within a device pixel of it (a shape on a fractional logical position, a text-derived width). A sheet passes at 93 % exact or 95 % near (or with fewer than 20 runs); `ERR` is an app that did not run to the end at that scale. The 1.0 reference is rendered with the whole-pixel snapping on too (`NEPER_LOOKS_EXACT`), so a shape the sheet put on a fractional logical position is not blurred in it. Method and tolerances: the header of the script. `before` is the exact share of the same sheets before the round 9 scale pass (master renders, this checker with only its rounding fixed).
