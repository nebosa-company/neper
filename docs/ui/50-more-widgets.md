# 50 popular Flutter UI packages

Snapshot: 2026-09-24.

Pub.dev measures popularity per package, not per individual widget. This list
ranks reusable Flutter UI/widget packages by the official
`downloadCount30Days` value from the [pub.dev score
API](https://pub.dev/help/api).

The candidate set came from download-sorted Flutter `ui` and `widget` topics
plus searches for common control families. Icon and font packs, state
management, routing, developer tools, pure themes, layout utilities, and
internal/platform implementation packages were excluded. Viewer and renderer
packages are included because they expose reusable Flutter widgets. This is a
curated category, not an official pub.dev “UI control” ranking.

## Reproducing the figures

For a package named `PACKAGE`, fetch:

```text
https://pub.dev/api/packages/PACKAGE/score
```

The response contains `downloadCount30Days`, `likeCount`, and the current pub
quality points. Download counts and likes are a moving snapshot and should be
refreshed before using this document as a future prioritization input.
