01 // why neper

Designed around the code review.

Generated code is cheap. Understanding it is not. Neper spends syntax on certainty so humans and tools can find, verify, and change the right thing quickly.

[ readable ]

Predictable source

No overloaded names. Explicit casts. One path, one module. A declaration is where grep says it is.

[ reproducible ]

Deterministic tools

The compiler works offline, emits stable artifacts, and checks its own self-hosted build.

[ native ]

Close to the machine

Arena memory and direct CPU/GPU code generation. No garbage collector. No LLVM in the pipeline.
