Contact the Neper project

The maintainers read the repository's issue tracker and the project chat. There is no other published contact channel; bug reports, build problems, documentation fixes and language questions all start in one of these two places.

GitHub issues

Open an issue at github.com/nebosa-company/neper/issues for a bug, a failing fixture, a feature request or a question about the language, the standard library or the build. The repository's suites, design decisions and history are next to it.

Discord

The project chat is at discord.gg/AdRneEsbCu, where the maintainers and other users discuss Neper and help with builds.

Before you write

The get-started page covers the clone, build and first program, and the blog has the benchmark methodology and reproduction notes. If your question is about a benchmark figure, the post and its scripts are the quickest reference.
