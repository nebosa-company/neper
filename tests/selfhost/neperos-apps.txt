# NeperOS apps and their fixtures, read by tests/selfhost/run.ps1 and run.sh (and kept in step with
# neperos/src/shell.e: the apps are the archive entries from 13 on, in this order; rng_server and net_server last are
# the network servers (D2247), started by the kernel when the machine has a network device, never launched by icon).
#   app|<source name>                         neperos/src/<name>.e, built to an image and put in the archive
#   fixture|<name>|<port>|<tap delay s>|<taps>|<markers joined by ;;>|<note>
#     boots the archive on QEMU with a tablet, sends the taps (tablet units, a delay between them) and
#     requires every marker, in order, on the serial output. Delay 0 leaves the default.
#   livefixture|<name>|<port>|<tap delay s>|<taps>|<markers joined by ;;>|<note>
#     the same, with a user-mode network and the host side of tests/selfhost/fixtures/neperos/net running
#     (DNS, HTTP, and HTTPS with recorded Coinbase and Twelve Data replies), the network server in test mode
#     (the fixture root, that DNS, port 443 dialled as 8443) -- an app's live data against recorded replies.
#   installfixture|<name>|<port>|<tap delay s>|<taps>|<markers joined by ;;>|<note>
#     the same, on the archive with a signed app package (the Level app, scripts/make_package.py) as its last entry.
#   diskfixture|<name>|<port>|<tap delay s>|<taps>|<markers joined by ;;>|<note>
#     a row named <base>_again, <base>_more or <base>_later boots again on the disk the row <base> left (a restart, more taps, or
#     forty days later: the guest clock is moved on), not on a fresh one.
#     the same, on a fresh 1 MB disk behind virtio-blk and a random-number device, and it ends at its LAST
#     marker (an app that leaves and is opened again prints its exit line more than once) -- an app's storage.
